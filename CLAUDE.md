# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a Claude Code plugin/skill called **Project Version Workflow (PVW)**. It provides a single skill (`/update-commit`) that automates versioned commits with dated tags (`vYYMMDD`), update log management, and optional push.

## Architecture

The project has no build system or runtime code. It is a pure skill/plugin definition comprised of metadata files and a skill specification:

- `.claude-plugin/plugin.json` — Plugin manifest (name, description, version).
- `.claude-plugin/marketplace.json` — Marketplace listing manifest. Contains a `plugins` array with the same metadata.
- `skills/update-commit/SKILL.md` — The full skill specification read by Claude Code when `/update-commit` is invoked. This is the authoritative behavior document.
- `update_log.txt` — Auto-generated by the skill itself; stores dated version history.

## Important Rules

When the `/update-commit` skill appends a new version to `update_log.txt`, also update the `version` field in both `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` to match the newest `vYYMMDD` format version generated by the skill.

## Installation Methods

The plugin can be consumed two ways:

1. **As a plugin (recommended):**
   ```bash
   /plugin install project-version-workflow@github.com/ATreep/project-version-workflow
   ```
   After installation, invoke via `/project-version-workflow:update-commit`.

2. **As a standalone skill:**
   ```bash
   cp -r skills/* ~/.claude/skills/
   ```
   Then invoke via `/update-commit`.
